# Humanitas

## Purpose of Humanitas:

1. Show users a good news feed. But not only that, show that it’s working. Give the data to the user and show that the world can be getting better. Help peel back the negative news layer that they are blinded by. Show the proof that it can be working.

2. Interrupt the doomscrolling the users could have. If a user get’s anxious or overwhelmed by the doomscrolling and algorithms of X, Tiktok, Instagram, etc, then have them come here, calm down, read a good long form article, and then stop. Don’t have endless scrolling on this app. Allow them to hit an end.
